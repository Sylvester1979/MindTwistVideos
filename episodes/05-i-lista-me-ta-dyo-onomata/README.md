# Επ. 05 · Η λίστα με τα δύο ονόματα (Ζάκυνθος, 1943–44)

Ο δήμαρχος Λουκάς Καρρέρ και ο Μητροπολίτης Χρυσόστομος καίνε τη λίστα με τους 275 Εβραίους του νησιού. Κατά τη δική τους αφήγηση, δίνουν στους Γερμανούς ένα χαρτί που έχει μόνο τα δικά τους ονόματα. Κανείς δεν παραδόθηκε.

| Στάδιο | Κατάσταση |
|---|---|
| 1. Πίνακας γεγονότων | Εγκρίθηκε → `data/facts.md` |
| 2. Σενάριο | Η v8 περιμένει την τελική έγκριση, μετά από έλεγχο αυτιού → `data/script_elevenlabs.txt`, εκτίμηση ~2:55 |
| 3. Storyboard | Εγκρίθηκε (v1, 38 πλάνα, 3 κλιπ 3D) → `data/SHOTS.md` |
| 4. Φωνή | Εγκρίθηκε: `voice_edit.wav` (2:56), από ολόκληρη λήψη + 2 διορθωμένες φράσεις (`edit_voice05.py`) |
| Ζωγραφιές | 8/24 έτοιμες. Το Replicate έμεινε χωρίς υπόλοιπο |
| 3D | Scripts έτοιμα (`blender/ep05-zakynthos/`), περιμένουν τα stills του χρήστη |

- **Κόκκινο στοιχείο:** η φλόγα που καίει τη λίστα.
- **Μοτίβο:** το χαρτί με τα δύο ονόματα, στα ελληνικά και στα γερμανικά.
- **Κλείσιμο:** καθρέφτης του επ. 04 («Μερικές λίστες σώζουν ανθρώπους με τα ονόματα που γράφουν»).
- **Αν η φωνή βγει πάνω από 3′,** κόβουμε πρώτα το «Σε λίγες εβδομάδες, φεύγουν κι οι Γερμανοί».
