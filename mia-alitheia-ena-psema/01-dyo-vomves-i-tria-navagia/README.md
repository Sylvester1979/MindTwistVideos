# Μία αλήθεια, ένα ψέμα · 01 · Δύο ατομικές βόμβες ή τρία ναυάγια;

(Κατά τη δουλειά λεγόταν «επ. 05», γι' αυτό τα αρχεία έχουν κατάληξη `05`.)

Νέα μορφή: ένας γύρος ανά βίντεο, έως 3′. Δύο απίθανες ιστορίες λέγονται και οι δύο σαν αληθινές, ο θεατής ψηφίζει, και στο τέλος αποκαλύπτεται η απάντηση.
**Καμία εικόνα AI.** Όλα (χάρτες, πλοία, σύννεφα, σφραγίδες, κάρτες, κίνηση) είναι κώδικας.

- **Α (αλήθεια):** Τσουτόμου Γιαμαγκούτσι, επέζησε από Χιροσίμα και Ναγκασάκι.
- **Β (ψέμα):** «Frank Tower», θερμαστής που δήθεν επέζησε από Τιτανικό, Empress of Ireland, Λουζιτάνια (αστικός θρύλος).

## Αρχεία
| αρχείο | τι κάνει |
|---|---|
| `lib05.py` | κάμερα πάνω σε «ρολό» χαρτιού, layers σε S=2 px/μονάδα, γραμμές που ζωγραφίζονται ζωντανά (πένα με πίεση), κείμενο γραφομηχανής, χαρτιά/props με σκιά, hatching σε συντεταγμένες καμβά, ακουαρέλα, παλέτα |
| `timeline05.py` | beats του σεναρίου. Χωρίς φωνή: εκτίμηση (2,58 λέξεις/″, παύσεις, γέφυρες, αντίστροφη μέτρηση). Με φωνή: αντικατάσταση από στοίχιση |
| `shots05.py` | άγκιστρο (κάρτες με λογοκριμένο κείμενο), ιστορία Α μέρος 1, μεταβάσεις, `frame(t)` |
| `story_a2.py` | ιστορία Α μέρος 2 (3 χλμ., σύννεφο, καρδιογράφημα, τρένο, πόρτα, αναφορά/φως, παράθεμα, γραμμή ζωής) |
| `story_b.py` | ιστορία Β (λεβητοστάσιο, καρτελάκι, παγόβουνο, Empress/ομίχλη/14′, 1915, τορπίλη, 18′, κολύμπι, «ποτέ ξανά») |
| `qr.py` | κάρτα Β που γεμίζει, ερώτηση + αντίστροφη μέτρηση, σφραγίδα/Χ, εξηγήσεις, φινάλε |
| `cards05.py`, `cardanim05.py` | οι κάρτες Α/Β, μανιτάρι, σφραγίδα «ΑΛΗΘΕΙΑ» (από τα δοκιμαστικά) |
| `render05.py` | `stills t…` / `video t0 t1 out.mp4` |
| `voice05.py` | συρραφή της ξαναγραμμένης τελευταίας φράσης, στοίχιση των 62 beats στις σιωπές (με διορθώσεις στο χέρι πάνω στην καμπύλη έντασης), παύσεις μοντάζ (γέφυρες, αντίστροφη μέτρηση) → `voice_edit.wav`, `timeline.json` |
| `voicefx05.py` | EQ (3,3 / 7,2 kHz, shelf 9 kHz) + δυναμικός de-esser 4,5–12 kHz → `voice_fx.wav` |
| `mix05.py` | φωνή + μουσική (Suno «One Truth One Lie (C)», id 2d8d5f9e) + 12 εφέ ElevenLabs στο συμβάν → `mix.wav` (−14 LUFS) |
| `subs05.py` | υπότιτλοι (≤ 6 λέξεις, ψηφία), όχι εκεί που το κείμενο είναι ήδη στο καρέ |
| `thumb05.py` | thumbnail σε κώδικα |
| `delivery.md` | τίτλος, περιγραφή, πηγές, tags, ρυθμίσεις, καρφιτσωμένο σχόλιο |

## Χρώμα (λίγο, ισορροπημένο)
Κάθε ιστορία έχει **ένα** κόκκινο αντικείμενο ώστε το χρώμα να μην προδίδει την απάντηση: Α = αποτύπωμα χάνκο, Β = σωσίβιο.
Κεχριμπαρί μόνο για φως (λάμψη, καμίνια, λάμπα), ξεθωριασμένο γκριζογάλανο για θάλασσα, μπλε μελάνι μόνο στο σχέδιο του δεξαμενόπλοιου. Η σφραγίδα «ΑΛΗΘΕΙΑ» στο τέλος.

## Σειρά
```
python3 timeline05.py                 # εκτίμηση χρόνων πριν υπάρξει φωνή (προεπισκοπήσεις)
python3 voice05.py                    # με τη φωνή: voice_edit.wav + πραγματικό timeline.json
python3 voicefx05.py                  # EQ + de-esser
python3 render05.py stills 12 35 …    # έλεγχος καρέ σε πλήρες μέγεθος
# ρεντερ σε κομμάτια των ~16″, δύο παράλληλα, ΠΑΝΤΑ σε εντολή που περιμένει (όχι στο παρασκήνιο)
python3 render05.py video 0 16 f00.mp4 & python3 render05.py video 16 32 f01.mp4 & wait
ffmpeg -f concat … -c copy video.mp4
python3 mix05.py                      # mix.wav
ffmpeg … 2-pass x264 8M + aac 256k    # τελικό ~183 MB
python3 thumb05.py
```
Το `$MT_ROOT` έχει επιπλέον: `audio/voice_ep05_v1.mp3`, `audio/cta_v2.mp3`, `music/music_ep05.wav`, `sfx/{paper,typewriter,pen,watch,rumble,train,furnace,hull,foghorn,torpedo,stamp,waves}.wav`.
